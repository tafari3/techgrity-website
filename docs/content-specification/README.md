## Content governance

- Public copy must not convert planned capability into fabricated completed delivery.
- Unknown company facts must be recorded as dependencies, not guessed.
- Client, partner, certification, project and numerical claims require publication evidence.
- Every detail page must answer a distinct buyer or evaluator question; thin repetition is not acceptable.
- Representative project types must always be labelled as examples, not completed case studies.
- Legal pages must match actual implementation and receive appropriate review before publication.
- Headings may be refined during visual design for line length, but the underlying message and page role may not change without updating this specification.
