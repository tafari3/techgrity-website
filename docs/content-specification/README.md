## Purpose

This directory defines the exact content role, message hierarchy, section order, calls to action, cross-links, imagery requirements, factual dependencies and page-specific acceptance conditions for every launch route.

## Required specification fields

Every page specification must define:

1. canonical URL;
2. audience and user intent;
3. business objective;
4. SEO intent;
5. recommended browser title;
6. recommended meta-description direction;
7. H1 and hero message;
8. ordered page sections;
9. primary and secondary calls to action;
10. mandatory internal links;
11. imagery or diagram brief;
12. factual dependencies and proof boundaries;
13. page-specific acceptance criteria.

## Content governance

- Public copy must not convert planned capability into fabricated completed delivery.
- Unknown company facts must be recorded as dependencies, not guessed.
- Client, partner, certification, project and numerical claims require publication evidence.
- Every detail page must answer a distinct buyer or evaluator question; thin repetition is not acceptable.
- Headings may be refined during visual design for line length, but the underlying message and page role may not change without updating this specification.
