## Infrastructure capability detail

Reference page: **Networks & Fibre**.

The user approved the design subject to these binding controls:

1. The condensed review-board height is not the final website height. The implemented page must use natural scrolling, proper hero height and documented section spacing.
2. Tiles under “What this capability covers” are informational sub-capabilities, not separate planned pages. They must therefore have no arrows, pointer cursor, fake hover affordance or click behaviour.
3. Cards may look navigational only when they lead to a real route or an approved in-page destination.
4. Homepage capability cards remain navigational because each one already has a planned detail-page destination.

## Global rule created by this decision

**Navigational cards**

- real destination;
- semantic link;
- keyboard focus;
- arrow or directional cue allowed;
- pointer and hover/focus treatment allowed.

**Informational cards**

- no destination;
- no arrow;
- no pointer cursor;
- no misleading hover lift;
- no fake control styling.

No dead card or destination-less tile may appear in production.
