# Techgrity Systems Master Visuals

This directory contains authoritative master-page visual references produced from actual HTML and CSS prototypes. Static screenshots are evidence of the rendered output; they are not substitutes for live implementation.

## Approval rule

A master template becomes implementation authority only when its folder contains:

- a desktop first-viewport reference;
- a mobile first-viewport reference;
- a full-page reference;
- tablet behaviour evidence or notes;
- prototype source or a reproducible rendering record;
- visual QA evidence;
- an approval record.
