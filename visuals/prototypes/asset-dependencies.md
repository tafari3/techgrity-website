The Wave 1 HTML/CSS prototypes reference approved or reviewed image assets from the verified homepage working package. Binary asset import is governed separately because every final production asset requires provenance, ownership/licence, crop and alternative-text review.

## Rule

These paths prove visual composition only. Before production implementation:

1. import the exact approved source assets;
2. record source and licence or ownership;
3. record desktop and mobile crops;
4. confirm technically plausible subject matter;
5. confirm whether the image is informative or decorative;
6. define accurate alternative text;
7. prevent representative imagery from being described as a completed Techgrity project.

The rendered-reference hashes in `../wave-1-reference-manifest.md` identify the exact reviewed output created with the working-package asset versions.
