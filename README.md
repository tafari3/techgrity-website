# Techgrity Systems Website

Official planning, design, implementation and evidence repository for the Techgrity Systems corporate website.

## Positioning

**Digital systems. Critical infrastructure. One accountable partner.**

Techgrity Systems designs, builds, integrates and supports software platforms, networks, data centres, telecommunications, power systems and technical infrastructure for organisations across Zimbabwe and Africa.

## Delivery sequence

1. Lock the website architecture.
2. Complete the master website specification.
3. Complete exact page-by-page content specifications.
4. Complete the visual design system and image art-direction brief.
5. Approve the authoritative master-page visuals.
6. Implement the website.
7. complete functional, responsive, accessibility, SEO and visual QA.
8. Deploy only after evidence-backed acceptance.

## Documentation

Authoritative project decisions and specifications are maintained under [`docs/`](docs/).

## Current status

The final sitemap and page architecture have been agreed. The repository is now being established as the source of truth for all subsequent planning, visual design, implementation and acceptance evidence.
